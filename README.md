# Clivoy Homebrew tap

The official Homebrew tap for [Clivoy](https://github.com/wklee610/clivoy):
your AI CLIs and model servers, one simple API.

## Install and start

```sh
brew install wklee610/clivoy/clivoy
clivoy start
```

Clivoy creates its configuration and gateway key on first start. Set up the CLI
or model server you want to use; see the [Quickstart](https://github.com/wklee610/clivoy#quickstart).

## Upgrade

```sh
brew upgrade clivoy
clivoy restart
```

The formula is updated automatically by Clivoy's release workflow.
